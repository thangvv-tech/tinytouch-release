Open-source biometric access

Your fingerprint. Your computer. Your control.

TinyTouch is an ESP32-S3 biometric key for local screen unlock, host pairing, and PIV SmartCard authentication on macOS and Linux.

Get StartedBuild Your Own

Designed to stay local.

TinyTouch keeps biometric access and host pairing close to the computer you use. No account or telemetry connection is required.

Local credentials

Host credentials stay in macOS Keychain or Linux Secret Service, not on TinyTouch.

One key, many hosts

Pair one TinyTouch key with up to 8 computers and move between them without re-enrollment.

HID or PIV

Use secure HID password typing or a CCID PIV SmartCard according to the host workflow.

TinyTouch Desktop

Set up access from one place.

Enroll fingerprints, store host credentials locally, switch between HID and PIV modes, and manage firmware or helper services before relying on lock-screen unlock.

Touch ID: enroll and test fingerprints stored as on-sensor templates.

Set Up TinyTouch

Start in three steps.

Pre-assembled devices normally arrive ready to use. DIY boards add firmware flashing first.

1

Connect TinyTouch

Use a data-capable USB cable directly on your computer and confirm the sensor LED ring flashes once during boot.

2

Install TinyTouch Desktop

Download the matching macOS disk image or Linux package from the latest GitHub Release.

3

Enroll and pair

Enroll a fingerprint in Touch ID, save your login credential locally in Passwords, then select Pair Machine and touch the sensor.

macOS setup, PIV SmartCard, CLI, and uninstall
  1. Download tinyTouch-<version>.dmg from GitHub Releases, open it, and drag TinyTouch.app into Applications.
  2. If Gatekeeper blocks first launch, open System Settings > Privacy & Security and select Open.
  3. In TinyTouch Desktop, enroll fingerprints under Touch ID, save your password in macOS Keychain under Passwords, select Pair Machine, and install the helper under Device.
  4. Lock the screen with Command-Control-Q and touch an enrolled finger to verify unlock.

Optional PIV SmartCard: switch to PIV Mode under Modes, then pair the token certificate with your macOS account:

sc_auth pairing_ui -s

Optional CLI: extract tinyTouch-<version>-darwin-universal.tar.gz into /usr/local/bin/ or ~/.local/bin/:

tinytouch status
tinytouch pair
tinytouch helper install

Uninstall: run Uninstall Helper in Device, delete /Applications/TinyTouch.app, and optionally clear Keychain with security delete-generic-password -s "tinytouch".

Linux setup (.deb, tarball, udev rules, PIV, and uninstall)

Debian / Ubuntu (amd64 or arm64): installing the .deb package configures binaries, udev rules, user helper service, desktop launcher, and PIV dependencies.

sudo apt install ./tinyTouch-*-linux-*.deb
systemctl --user start tinytouch-helper
tinytouch-desktop

Portable archive (Fedora, Arch, openSUSE): extract tinyTouch-<version>-linux-*.tar.gz into ~/.local/bin/ and add USB udev rules for TinyTouch (303a:4001):

tar -xzf tinyTouch-*-linux-*.tar.gz
cd tinyTouch-*-linux-*
mkdir -p ~/.local/bin
cp tinytouch tinytouch-desktop tinytouch-helper ~/.local/bin/
chmod +x ~/.local/bin/tinytouch*

sudo tee /etc/udev/rules.d/99-tinytouch.rules > /dev/null <<'EOF'
SUBSYSTEM=="tty", ATTRS{idVendor}=="303a", ATTRS{idProduct}=="4001", MODE="0666", TAG+="uaccess"
SUBSYSTEM=="usb", ATTRS{idVendor}=="303a", ATTRS{idProduct}=="4001", MODE="0666", TAG+="uaccess"
EOF

sudo udevadm control --reload-rules
sudo udevadm trigger --subsystem-match=tty --attr-match=idVendor=303a
sudo udevadm trigger --subsystem-match=usb --attr-match=idVendor=303a

Reconnect TinyTouch after reloading udev. Open TinyTouch Desktop (supports English and Tiếng Việt), or use the CLI: tinytouch status, tinytouch password, tinytouch pair, and lock with Super-L.

Optional PIV SmartCard: install pcscd opensc libccid libpam-pkcs11 (Debian/Ubuntu), pcsc-lite opensc ccid pam_pkcs11 (Fedora), or pcsclite opensc ccid pam_pkcs11 (Arch), enable sudo systemctl enable --now pcscd, and run tinytouch mode piv.

Uninstall: sudo apt purge tinytouch, or for portable installs run tinytouch helper uninstall and remove ~/.local/bin/tinytouch*, ~/.local/share/applications/tinytouch.desktop, and /etc/udev/rules.d/99-tinytouch.rules.

DIY hardware

Build TinyTouch your way.

Wire an ESP32-S3 SuperMini or Seeed Studio XIAO ESP32-S3 to a supported optical UART fingerprint sensor. Print the matching snap-fit STL or STEP enclosure and flash firmware below.

Browse Enclosure Files

Parts and wiring.

Solder five 30 AWG flexible silicone wires (about 35 mm long) between the optical sensor and ESP32-S3.

3.3V only. Connecting sensor VCC to 5V permanently damages the optical module.

  • Print settings: FDM or SLA resin; PETG recommended (PLA/ABS work); 0.16–0.20 mm layer height; 20–30% gyroid or grid infill; flat exterior faces on the build plate; no supports needed.
  • Fit & assembly: 0.2 mm snap-fit tolerance (scale to 100.5% if tight). Thread the 5-pin harness through the top opening, seat the sensor flush in the bezel, solder ~35 mm wires, align USB-C in the bottom shell, and snap shut.

Use the offline flash bundle (macOS, Linux, Windows)

Download tinytouch-<version>-firmware.zip and extract it. If the script reports esptool is missing, install Python 3 and run pip install esptool.

unzip tinytouch-*-firmware.zip
cd tinytouch-*-firmware
chmod +x flash.sh
./flash.sh

On Windows, double-click flash.bat or run it from Command Prompt.

OTA update from TinyTouch Desktop

For devices already running firmware v0.1.0 or newer: open TinyTouch Desktop > Device, choose Update Firmware Online or select a downloaded tinytouch.bin, then select Install OTA Update.

Enter ROM bootloader mode
  1. Unplug the USB cable.
  2. Hold the physical BOOT button on the ESP32-S3 board.
  3. Reconnect USB while holding BOOT.
  4. Release after 2 seconds, then retry flashing.

Help when it matters.

Check cable, USB permissions, and sensor glass before changing your configuration.

TinyTouch is not detected

Use a data-capable USB cable connected directly to your computer (unpowered hubs can drop voltage). On Linux, install the .deb package or add the udev rule for 303a:4001, then replug the device.

Fingerprint matching fails

Clean the optical glass with a microfiber cloth and re-enroll the finger from slightly different angles. Very dry skin reduces optical contrast; test with a lightly moistened fingertip.

Lock screen types wrong characters

In TinyTouch Desktop, open Modes and set the matching physical keyboard layout: US, UK, DE, FR, HR, or Auto.

Auto-unlock does not work

Keep the lock-screen password field focused before touching the sensor. Verify the helper service is running: launchctl list | grep com.tinytouch.helper (macOS) or systemctl --user status tinytouch-helper (Linux).

Can a stolen key reveal the host password?

No. TinyTouch stores biometric templates and pairing keys only. Host unlock passwords remain encrypted in macOS Keychain or Linux Secret Service, and unlock requires both the paired machine and an enrolled fingerprint.
